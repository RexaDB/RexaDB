# Rexa DB
> Multi-database desktop client for PostgreSQL, MySQL, MongoDB, SQLite, ClickHouse, Redis, and SQL Server.

## Key Features
- **Multi-Database Connectivity**: Manage connections for 100+ databases including PostgreSQL, MySQL, MongoDB, SQLite, ClickHouse, Redis, and SQL Server
- **Powerful Query Editor**: Monaco-based SQL editor with syntax highlighting, auto-complete, and query history
- **Data Visualization**: Interactive charts, graphs, and AG Grid-powered table views for query results
- **AI Integration**: Built-in support for AI-assisted query generation and optimization (Anthropic, Google, OpenAI)
- **Connection Management**: Save, organize, and quickly switch between database connections with analytics
- **Cross-Platform Support**: Download builds for macOS (arm64/Intel), Windows, and Linux from Releases
